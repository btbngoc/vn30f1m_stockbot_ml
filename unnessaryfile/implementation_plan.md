# Revised Project Architecture Implementation Plan

## Goal Description

Restructure the VN30F1M stock bot to a lean, single‑file‑per‑concern layout while keeping all functionality:

```
VN30F1M-stockbot/
│
├── config.py                     # central configuration
├── run_pipeline.py                # orchestrator with mode flags
│
├── data/
│   ├── VN30F1M_since20180501.csv
│   ├── VN30F1M_features.parquet   # generated by indicator.py (stored in data/)
│   ├── loader_csv.py
│   ├── indicator.py               # computes **all** indicators and writes parquet
│   ├── update_csv.py
│   └── vci_api.py
│
├── ml/
│   ├── dataset.py
│   ├── model.py
│   ├── train.py
│   └── predict.py
│
├── backtest.py                    # backtest engine, outputs trades & equity CSVs
├── analysis.py                    # extensive trade statistics (MAE, MFE, R‑multiple, SQN, Kelly, Expectancy, Recovery Factor, Profit/hour, Profit/day, Holding Time, Rolling DD, Rolling Winrate, etc.)
├── visualize.py                   # single offline Plotly visualiser with helper functions
├── report.py                      # generates HTML report, exports CSVs (including feature_importance.csv) and PNG screenshot
│
├── models/                        # persisted models
├── results/                       # per‑run output folder (date‑based subfolders)
└── tests/                         # unit / integration tests
```

### Key Design Decisions
- **No `features/` folder** – the parquet lives inside `data/` (`VN30F1M_features.parquet`).
- **Single visualiser file** (`visualize.py`) containing all helper functions:
  `load_data()`, `draw_candle()`, `draw_indicator()`, `draw_trade()`, `draw_dashboard()`, `draw_heatmap()`, `draw_equity()`, `draw_feature_importance()`, `save_html()`.
- **Single report file** (`report.py`) that bundles HTML generation, CSV exports (trades, equity, feature importance), and screenshot creation.
- **Single analysis file** (`analysis.py`) implementing a comprehensive metric suite.
- **Backtest** collapsed into `backtest.py`.
- **Feature importance** exported to `results/<date>/feature_importance.csv` for easy Excel/Git diff.
- **`run_pipeline.py`** uses absolute imports (`from trading_engine.data import update_csv`) to avoid import errors when run from any directory.
- **Pipeline order**: `update_csv → indicator → train → predict → backtest → analysis → report → visualize`.
- **VWAP** remains computed in `indicator.py` and stored in the parquet.
- **Merge tolerance** stays at 1 minute.
- **Plotly offline** – no Dash, pure HTML/JS output.
- **Config** remains a single `config.py` file.

## Proposed Changes

### 1. `config.py`
- Update `FEATURES_PARQUET` to `DATA_DIR / "VN30F1M_features.parquet"`.
- Add helper `RESULT_DATE = datetime.now().strftime("%Y-%m-%d")` and `RUN_RESULT_DIR = RESULT_DIR / RESULT_DATE`.

### 2. Remove `features/` directory
- Delete folder and any imports referencing it.

### 3. `data/indicator.py`
- After computing indicators, write to `FEATURES_PARQUET` (now in `data/`).
- Keep CLI `main()`.

### 4. `visualize.py`
- Implement the nine helper functions listed above. All code stays within a single file (~800‑1200 LOC).
- Use Plotly offline, export `chart.html` and `screenshot.png` into `RUN_RESULT_DIR`.

### 5. `report.py`
- Generate an HTML report that embeds `chart.html`, displays dashboard JSON, and shows tables for trades, equity, and feature importance.
- Export CSVs (`trades.csv`, `equity.csv`, `feature_importance.csv`) into `RUN_RESULT_DIR`.
- Save PNG screenshot.

### 6. `analysis.py`
- Load `backtest_trades.csv` and compute:
  - MAE, MFE, R‑multiple, SQN, Kelly, Expectancy, Recovery Factor, Profit/hour, Profit/day, Holding Time, Rolling DD, Rolling Winrate, plus any existing metrics.
- Write `analysis.csv` to `RUN_RESULT_DIR`.
- Provide `print_summary()` for console output.

### 7. `backtest.py`
- Consolidate logic from the previous `backtest/engine.py`.
- Output `backtest_trades.csv` and `equity_curve.csv` to `RUN_RESULT_DIR`.

### 8. `run_pipeline.py`
- Use absolute imports, e.g. `from trading_engine.data import update_csv`.
- Add flags: `--update`, `--feature`, `--train`, `--predict`, `--backtest`, `--analysis`, `--report`, `--visualize`, `--all`.
- Implement ordered execution respecting the new pipeline flow.

### 9. Tests
- Relocate/adjust tests to the new paths (`tests/` folder).
- Add tests for the new analysis metrics and for the existence of exported `feature_importance.csv`.

### 10. Documentation
- Update `README.md` (if present) with the new directory layout and usage examples.
